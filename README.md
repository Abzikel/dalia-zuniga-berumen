This repository centralizes interactive web activities, coursework resources, and WebAR experiences created to support **Dalia Zuniga Berumen** with her academic and instructional design projects.

All activities are built as static web pages and published via GitHub Pages under a dedicated subpath (`https://abzikel.dev/dalia-zuniga-berumen/`), kept independent from the main portfolio site.

## Activities

| Activity | Description | Path |
| :--- | :--- | :--- |
| **Bitacora de Trabajo** | Work log and reflection activity (Unit 6 - UAG) | [`activities/bitacora-de-trabajo/`](activities/bitacora-de-trabajo/index.html) |
| **Desarrollo Profesional** | Self-evaluation and professional development route for instructional design | [`activities/desarrollo-profesional/`](activities/desarrollo-profesional/index.html) |
| **Estrategias Digitales** | Learning strategies for digital environments | [`activities/estrategias-digitales/`](activities/estrategias-digitales/index.html) |
| **Evolucion de las Teorias Educativas** | Educational theories and their influence on instructional design | [`activities/evolucion-de-las-teorias-educativas/`](activities/evolucion-de-las-teorias-educativas/index.html) |
| **Mapa Conceptual - Tipos de Aprendizaje** | Interactive concept map covering types of learning | [`activities/mapa-conceptual-tipos-de-aprendizaje/`](activities/mapa-conceptual-tipos-de-aprendizaje/index.html) |
| **Plagio y Atribucion** | Academic AI module with interactive tabs and downloadable course syllabus (`.docx`) | [`activities/plagio-y-atribucion/`](activities/plagio-y-atribucion/index.html) |
| **Presentacion AR** | WebAR experience (*5 momentos del Espanol*) built with A-Frame and MindAR image tracking | [`activities/presentacion-ar/`](activities/presentacion-ar/index.html) |
| **El Tribunal de la IA** | Interactive AI ethics and critical thinking activity | [`activities/tribunal-de-la-ia/`](activities/tribunal-de-la-ia/index.html) |
